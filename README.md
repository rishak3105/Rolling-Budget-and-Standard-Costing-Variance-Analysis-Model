# Rolling-Budget-and-Standard-Costing-Variance-Analysis-Model
12-month rolling budget and sales/overhead variance analysis with assumptions and dashboard
# Overview
- 12-month rolling budget and forecast (6 months actual + 6 forecast) using standard costs, departmental overhead rates and inflation/efficiency assumptions.
-	Explained results via standard cost, sales and overhead variances in a profit bridge tied to reported profit.
-	Delivered a management dashboard with monthly profit tracking and commentary
